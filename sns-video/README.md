# リール動画の自動作成（ffmpeg版・試作）

台本のCSVと画面録画の素材から、Instagramリール用の縦長動画（1080×1920、30fps、MP4）を自動で作ります。無料のツールだけで動きます。

## 準備（最初に1回だけ）

1. **ffmpeg をインストール**
   - Mac: `brew install ffmpeg`
   - Windows: `winget install ffmpeg`
2. **Python 3.8以上**（Macには最初から入っています。追加のライブラリは不要です）
3. **画面録画を `clips/` に入れる**（ファイル名は CSV の `clip` 列に合わせる）

| ファイル名 | 中身 | 目安 |
|---|---|---|
| `clips/zatsudan.mp4` | 雑談配信の画面録画 | 3〜5秒 |
| `clips/uta.mp4` | 歌配信の画面録画 | 3〜5秒 |
| `clips/game.mp4` | ゲーム配信の画面録画 | 3〜5秒 |

- 録画が指定した秒数より短い場合は、くり返し再生でつなぎます
- 配信者の顔・名前が映る場合は、本人の許可がない限り、録画の段階でぼかすか、ASPの公式素材を使ってください
- 素材を入れていない場合は、どこに何を入れるかを書いた仮の枠で動画を作ります（レイアウトの確認用）

## 録画なしで作る（mockレイアウト）

`layout` を `mock` にすると、画面録画を使わずに**配信画面のイメージ**（LIVE表示、ジャンル名、0.6秒ごとに1つずつ表示されるコメント）をプログラムで描きます。画面の右下には「※画面はイメージです」と自動で入ります。

```bash
python3 make_video.py scripts/reel_b_genre_nofootage.csv
```

`mock` 列に「タイトル|コメント1|コメント2|コメント3」の形で書きます（コメントは4つまで）。`accent` 列で配信エリアの色を変えられます。

| 列 | 例 |
|---|---|
| `mock` | `♪ 歌配信\|この曲すき！\|声きれい\|アンコール` |
| `accent` | `#F2A7C3` |

実際のアプリの画面とは違う「イメージ」なので、実在のアプリ画面や実際の数値（視聴者数、ランキングなど）のように見せる表現は入れないでください。

## Gemini（Veo）でイメージ映像を作る

`gen_broll.py` は、Gemini API の動画生成（Veo）で、夜の部屋やスマホを持つ手元などの**イメージ映像**を作り、`clips/` に保存します。作った映像は、台本CSVの `clip` 列で指定するとそのまま使えます。

```bash
export GEMINI_API_KEY=...        # Google AI Studio（https://aistudio.google.com）で発行
python3 gen_broll.py scripts/broll_prompts.csv
python3 make_video.py scripts/reel_a_veo.csv
```

- 作る映像の内容は `scripts/broll_prompts.csv` に英語で書きます（英語の方が意図どおりになりやすい）
- **Veo の動画生成は有料**です。料金は Google AI Studio で確認してください
- 使うモデルは環境変数 `GEMINI_VIDEO_MODEL` で変えられます（モデル名は変わることがあります）
- 顔の映った人物は作らない設定にしています。AIで作った人物に体験談を話させると、実在しない体験談になり、ステマ規制や景品表示法の問題になります
- Instagramでは、本物に見えるAI生成の映像に「AI情報」ラベルを付けることが求められます

## 録画の代わりに使える素材

| 素材 | 使い方 | 注意 |
|---|---|---|
| **ASP・広告主の公式素材**（動画バナー、スクリーンショット） | ダウンロードして `clips/` に入れる | 一番おすすめ。使ってよい媒体・加工の可否を案件ページで確認する |
| **無料のストック動画**（Pexels、Pixabayなど） | 「夜の部屋」「スマホを持つ手」などを縦長で探して `clips/` に入れる | 商用利用OKのものを選ぶ。映っている人物を利用者の体験談のように見せない |
| **mockレイアウト** | 上の方法。素材は不要 | 「イメージ」であることを表示する（自動で入る） |
| **Gemini（Veo）のAI映像** | `gen_broll.py` で作る | 有料。人物の顔や体験談には使わない。InstagramのAIラベルを付ける |

## 動画を作る

```bash
cd sns-video
python3 make_video.py scripts/reel_b_genre.csv        # CSV内の全動画
python3 make_video.py scripts/reel_b_genre.csv b02    # IDを指定して1本だけ
```

`output/` に `b01.mp4`（動画）と `b01_cover.jpg`（カバー画像）ができます。

## 台本CSVの書き方

1行が1シーンです。`video_id` が同じ行が1本の動画になり、`scene` の順につながります。Googleスプレッドシートで編集し、「ファイル → ダウンロード → CSV」で保存しても使えます。

| 列 | 内容 | 例 |
|---|---|---|
| `video_id` | 動画のID（出力ファイル名になる） | `b01` |
| `scene` | シーンの順番 | `1` |
| `duration` | 秒数 | `3` |
| `layout` | `full`（全画面）、`frame`（中央にスマホ画面の枠＋録画）、`mock`（録画なしで配信画面のイメージを描く） | `frame` |
| `clip` | 素材の動画（空欄なら背景色だけ） | `clips/uta.mp4` |
| `text` | テロップ。`\n` で改行 | `あなたが\n沼る配信ジャンルは\nこれ` |
| `pos` | テロップの位置：`center`（中央）または `top`（上） | `top` |
| `bg` | 背景色 | `#F9D9E7` |
| `size` | 文字の大きさ（長い行は画面に収まるよう自動で小さくなる） | `72` |

サンプルの `scripts/reel_b_genre.csv` には、最初の1文（フック）だけを変えた2本（`b01`、`b02`）が入っています。どちらが伸びるかを比べる、A/Bテスト用です。

## 自動で入るもの

- **「PR」表記**：全シーンの左上（Instagramのボタンに隠れない位置）
- **テロップ**：上15%・下25%（Instagramのボタンやキャプションに隠れる範囲）を避けて配置
- **動き**：2シーン目以降のテロップは、0.3秒で下からふわっと表示。1シーン目（フック）は最初のフレームからはっきり表示
- **無音の音声トラック**：音源は、Instagramに投稿するときに流行りの音源を付けてください

## 注意

- テロップに**絵文字は使えません**（表示されません）。絵文字を入れたい場合は、キャプションに入れてください
- 色や枠の大きさなどの全体の設定は、`make_video.py` の上の方にまとめてあります
- 同じ素材ばかり使うと、Instagramに「似た動画の量産」と判断されやすくなります。素材は月に1回ほど撮り足してください
