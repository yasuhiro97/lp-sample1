# プロフィール文と紹介ページの使い方

## 1. Instagramのプロフィール（3案）

名前欄は検索に出る部分なので、**「配信」「寝る前」など、探される言葉**を入れます。自己紹介欄は150文字以内です。

### A案：共感型（おすすめ）

- **名前**：ゆめ｜寝る前の配信ログ
- **自己紹介**
```
寝る前のスマホ、流し見より配信派🌙
大学生の夜ふかしあるある／配信の楽しみ方
広告(PR)を含みます｜18歳以上向け
👇配信アプリの紹介はこちら
```

### B案：情報型

- **名前**：まい｜配信の見つけ方
- **自己紹介**
```
雑談・歌・ゲーム、ジャンル別に配信を紹介
寝る前の30分だけ、ゆるく楽しむ派
PR投稿あり／18歳以上の方向け
👇紹介ページ
```

### C案：診断型

- **名前**：ことり｜推し配信診断
- **自己紹介**
```
あなたに合う配信ジャンル、診断します🔮
毎週月〜金に投稿
広告(PR)を含みます／18歳以上向け
👇アプリの紹介はこちら
```

名前は例です。**実在の人物や既存のアカウントと紛らわしくならないもの**にしてください。

### プロフィール作成の注意

- 「PR」「広告」の表記を**プロフィールにも入れる**（投稿ごとの表記と別に、アカウント全体の姿勢として示すため）
- 「稼げる」「絶対」「完全無料」などは書かない
- 顔写真や他人の写真をアイコンに使わない。**自作のイラストやロゴ**にする（実在の人物に見せない）
- 18歳未満の人に向けた書き方（制服・「JK」など）をしない
- リンクは**1つだけ**（紹介ページのURL）。ASPのリンクを直接貼らない

## 2. ハイライト（プロフィール下の丸いアイコン）

| 名前 | 中身 |
|---|---|
| はじめに | このアカウントで何を紹介しているか、PR表記の説明 |
| 配信とは | 雑談・歌・ゲームの見え方（イメージ画像） |
| 診断 | 反応が良かった診断系のストーリー |
| Q&A | よくある質問（お金、顔出し、コメントの要否など。**事実だけ**） |

## 3. 固定投稿（先頭に並べる3本）

1. 一番反応が良かった「診断」のリール
2. 「寝る前の30分」あるあるのリール
3. アプリの紹介（PR表記つき、紹介ページへの誘導）

## 4. 紹介ページ（`landing/index.html`）の設定

ファイルの中の次の5か所を書き換えます。**書き換えるまでは、ボタンが動かず、画面の上に黄色い注意が出ます**（広告リンクが空のまま公開されるのを防ぐため）。

| 書き換える場所 | 内容 |
|---|---|
| `AFFILIATE_URL`（ファイル下部の `<script>` の中の1か所だけ） | ASPで発行した紹介リンク。ボタンのリンクは、この値で自動的に置き換わります（ボタン側の `REPLACE_WITH_AFFILIATE_URL` は触らなくて大丈夫です） |
| `SUBID_PARAM` | ASPのサブIDのパラメータ名（任意） |
| `【アプリ名】` | 実際のアプリ名（ページ全体） |
| `【要確認：…】` | 提携先の公式ページで確認した**事実**に置き換える（無料の範囲、登録に必要なもの、所要時間など）。確認できないものは**文章ごと消す** |
| フッターの `【ニックネームなど】`、`【連絡先】` | 運営者情報 |

### アクセス元の見分け方（サブID）

プロフィールのリンクは1つしか貼れないため、**場所ごとに末尾の目印を変えます**。

| 貼る場所 | リンク |
|---|---|
| Instagramのプロフィール | `https://（紹介ページ）/?src=ig_bio` |
| Instagramのストーリー | `https://（紹介ページ）/?src=ig_story` |
| Xのプロフィール・投稿 | `https://（紹介ページ）/?src=x` |

`SUBID_PARAM` を設定すると、この目印がASPのサブIDとして引き継がれ、**ASPの管理画面で「どこから登録が出たか」を見られる**ようになります。サブIDに対応していない案件では使えません。

> リールには、投稿そのものにリンクを貼れません。リールからの登録は、プロフィール経由（`ig_bio`）に入ります。動画ごとの違いは、**登録数とリールの再生数・プロフィールへのアクセス数を、同じ週で比べる**ことで見ます。

## 5. 公開するとき

- 紹介ページは静的な1ファイルなので、Netlify・Cloudflare Pages・Vercelなどの**無料の静的ホスティング**に `landing/` フォルダごとアップロードすれば公開できます
- このリポジトリのGitHub Pagesはルートの `index.html`（LP見本）を使うので、紹介ページを同じ場所に出したい場合は、公開の設定を別途行います
- 公開前に、次の確認をしてください

### 公開前チェック

- [ ] ページ上部の黄色い注意（「設定が必要」）が出ていない（＝ `AFFILIATE_URL` が入っている）
- [ ] `【` で始まる未記入の項目が残っていない
- [ ] 記載した内容（無料の範囲、登録の条件）が、提携先の公式ページと**一致している**
- [ ] ASPの規約で、**ブリッジページ（中継ページ）を使ってよい**ことを確認した（案件によっては禁止、または事前申請が必要）
- [ ] ASPの規約で、使ってはいけない表現（NGワード）に触れていない
- [ ] 「PR」の表記が、ページの上部とフッターにある
- [ ] スマホで、ボタンが押せて、文字が読める

## 6. このページは何のため？

プロフィールのリンクから**いきなりアプリの登録ページに飛ばすより**、「どんなものか」「お金や安全面は大丈夫か」を先に伝えるほうが、登録完了まで進む人が増えると考えています。ただし、これは仮説です。実際の効果は、ASPの管理画面で**紹介ページのクリック数と登録数を比べて**確かめてください。
